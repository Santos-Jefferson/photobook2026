h1. Photobook — What's New (MVP / Demo)

{info:title=One-liner}
*Photobook* is the new layer we built on top of *Capsyl*: turn a *Memory*, a *Photos* selection, or a fresh upload into a swipeable, AI‑narrated photo‑book story — then refine it by chat, re‑style it, and export it to share.
{info}

{note:title=Scope of this page}
This page only covers the *new* capabilities we demo. Everything else (Home, Photos, Memories browsing, Explore, Library, top bar, etc.) already exists in Capsyl and is reused as‑is.
{note}

{toc:maxLevel=2|minLevel=2}

----

h2. What we're presenting

# *Photobook from a Memory* — one tap.
# *Photobook from Photos* — multi‑select → one tap.
# *Photobook from scratch* — full options + AI insights & auto title/context.
# *Chat on each photobook page* — edit a page in natural language.
# *Chat on a single photo* — one‑tap restyle / quick edits.
# *Edit photobook at the end* — re‑generate with a new style + mood.
# *Narration* — play the story aloud, pick language & voice.
# *Export & share* — PDF · HTML · narrated 9:16 video.

{tip:title=Suggested demo order (≈3 min)}
Memory → Photobook *(the hero)* → peek the *Photos* multi‑select entry → open a *Saved* book and *Chat‑edit* a page (+ greeting card) → *Edit photobook* (restyle) → *Narrate* + *Share → video*. Close with *Chat on a single photo* (one‑tap Anime). Pre‑generate one book so you never wait on the API live.
{tip}

h2. Design principles

* *Mobile‑only, by design* — the app is always a centered phone column, even on desktop, so everyone gets the Capsyl mobile feel behind a single URL.
* *Feels like Capsyl* — it slots into the existing app (Memories → Photobook, a *Create Photobook* action in Photos), reusing Capsyl's shell, icons and navy/teal nav.
* *One tap to delight* — a Memory or a Photos selection becomes a finished, narrated story in a single action; choices are reserved for the deliberate "from scratch" path.
* *AI does the heavy lifting* — it reads the photos to suggest title, context, themes and mood, and can soften the whole story into a bedtime read.
* *Resilient* — graceful fallbacks everywhere (browser TTS if the narration server is down; original photo when no styled image returns; manual title/context with a visible notice when the analyze service is unreachable).
* *Private by default* — books, memories, photos and people live locally in IndexedDB; photos leave the browser only to reach the Genius API and our own {{/api/*}} endpoints.

h2. 1. Photobook from a Memory (one tap)

Open a Memory → *Create photobook*. No questions asked — it generates immediately with sensible defaults (*Retro Toons* style, *heartwarming* mood, *AI Storyteller*), folding the photos' date/place into the prompt automatically.

{noformat}

│ 5 photos · Jun 2026            │
│  [ ✨ Create photobook ]        │ → generates instantly (defaults)
└───────────────────────────────┘
{noformat}

h2. 3. Photobook from scratch (full control + AI)

The *Creator* is the deliberate path. Upload photos *or* *Choose from Photos* (the library), let the AI suggest everything, then tune the options.

* *✨ What we noticed* — themes, mood, highlight and people, read from the chosen photos.
* *Auto title + context* — suggested from the photos (editable; "Regenerate" to vary).
* *From your photos* — date/place (EXIF) folded into the context.
* *Options* — mood, art style, narrator perspective, stylize, and *🌙 Bedtime story* (retell gently for a child).

{noformat}
┌───────────────────────────────┐
│        ● Photobook             │
│  Your photos            3/5    │
│  [▢][▢][▢]                     │
│  [⬆ Upload]  [🖼 Choose from …]│
│  ✨ What we noticed   [Analyze] │
│   #family #travel · Mood: warm │
│   Highlight: the cake moment   │
│  Title  [ A Day at the Lake ]  │  ← auto‑filled
│  Context[ A sunny family … ]   │  ← auto‑filled

h2. 4. Chat on each photobook page

Inside the story, every photo page has *✦ Edit* → a chat panel scoped to that page:
restyle/edit the image in natural language, apply a style preset, run *memory actions*
(Child's POV / Funnier / More emotional / Translate), and generate a *Genius greeting card*.
Results apply live to the page (image, caption, or narrative).

{noformat}
┌──────── Edit this photo ───────┐
│ [Child's POV][Funnier][More…]  │  ← memory actions (text)
│ [Translate ▾]   [✨ Greeting]   │
│ you: make it watercolor        │
│ ai:  ✓ applied (Watercolor)    │
│      [Use as caption][…narr.]  │
│ (style ▾) [Apply]  type…  [Send]│
└────────────────────────────────┘
{noformat}

h2. 7. Narration

A bottom bar plays the story aloud (neural TTS), advancing slide‑by‑slide. A sheet picks the
*language* (the visible text translates to match) and the *voice* (Female / Male / Child).
Falls back to the browser voice if the narration server isn't reachable.

{noformat}
┌───────────────────────────────┐
│  … story slide …               │
│ [▶ Narrate]  [🌐 EN · Female]  │  ← narration bar
└───────────────────────────────┘
        ┌──────── Narration ────────┐
        │ LANGUAGE [EN•][PT][ES][…] │
        │ VOICE    [Female•][Male]  │
        │            [   Done   ]   │
        └────────────────────────────┘
{noformat}

h2. 8. Export & share

From the final page, *⤓ Share & export*:

* *PDF* — print‑ready, with all‑photo collage covers.

* *Narrated video* — a 9:16 Stories clip (collage covers + each photo + narration), styled
  to match the on‑screen story; ready for *WhatsApp / Instagram*.

h2. Architecture

The new Photobook layer is a *React 18 + Vite* SPA, served as a Capsyl‑style phone column.
Generation and per‑photo edits call the *Genius Narration API*; narration, translation,
perspective and the free‑form rewrites that power *bedtime / insights / auto title* go through
our own {{/api/*}} endpoints (msedge‑tts + an internal Qwen LLM). Saved books, memories, photos
and people live locally in IndexedDB.

{noformat}
   Create paths                         ┌─ Genius API ──────────────────────────┐
   Memory ─┐                            │  /photobook        (generate + style) │
   Photos ─┤ one tap (defaults)         │  /photo-chat       (edit · Q&A · ins.) │
   Creator ┘ options + insights         │  /greeting-card                       │
        │                               └───────────────────────────────────────┘
        ▼                  generate                  ▲
   App.jsx (view state machine) ──────────────────────┘
        │  normalizeBook → perspective → (bedtime)
        ▼
   StoryViewer ── narration · translate · chat · edit · export
        │                      │
        ▼                      ▼
   our /api/* (Node)     IndexedDB (books · photos · memories · people)
   narrate (msedge‑tts)
   translate · perspective · rewrite (Qwen)   ← bedtime · insights · auto‑title
{noformat}

||Route||Purpose||Backed by||
|POST /v1/genius/photobook|Generate a story from photos|Genius API|
|POST /v1/genius/photo-chat/analyze · message · ask|Per‑photo edit / Q&A / insights|Genius API|
|POST /v1/genius/greeting-card|Greeting card|Genius API|
|POST /api/narrate|Narration audio|msedge‑tts|
|POST /api/translate · /api/perspective · /api/rewrite|Translate · POV · rewrite (bedtime/insights/title)|internal LLM (Qwen)|

*Tech stack:* React 18 + Vite 5, hand‑written CSS (no router — a small {{view}} state machine).
Browser libs: {{exifr}} (EXIF/GPS), {{jspdf}} + {{html2canvas}} (PDF / cover), Canvas +
{{MediaRecorder}} (in‑browser narrated video), Shape Detection {{FaceDetector}} (People).

*Deployment:* source in *Bitbucket / Stash*; a *Bamboo* plan builds the Docker image, pushes it
to *ECR*, and deploys to *Kubernetes* (Helm chart in {{deployment/helm}}, or a plain
{{kubectl}} manifest for a new namespace). One container runs {{server/index.js}}, serving the
SPA *and* {{/api/*}}; {{/healthz}} backs the probes. See the README for step‑by‑step install.
